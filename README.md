# Impusla_Recibe
En resumen, Impulsa+Recibe ayudará a dar visibilidad a causas solidarias y permitirá que las personas colaboren mediante donaciones simuladas. A cambio, acumularán puntos para canjear regalos dentro de la aplicación. La desarrollaremos para Android con Java, Firebase y GitHub, con un alcance que podamos completar entre tres personas.
